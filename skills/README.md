# ESP Mosaico example skills

## Skill list

| Skill | Purpose |
|-------|---------|
| [`espressif-env-setup`](espressif-env-setup/SKILL.md) | Install a fresh ESP-IDF, ESP-AT, or ESP-ADF environment and verify the first build. |
| [`idf-low-noise-build`](idf-low-noise-build/SKILL.md) | Run low-noise ESP-IDF builds with complete logs and focused failure diagnostics. |
| [`gsp-sim`](gsp-sim/SKILL.md) | Preview GSP scenes on PC with the standalone sim matching submodule/esp-gsp 1.1.0. |
| [`esp-iris-device-debugging`](esp-iris-device-debugging/SKILL.md) | Diagnose ESP-Iris connectivity, boot, update, Recovery, panic, and core-dump failures while preserving evidence. |
| [`mosaico-game-development`](mosaico-game-development/SKILL.md) | Create, extend, test, package, and install ESP-Mosaico Raylib games. |
